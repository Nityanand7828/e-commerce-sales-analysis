# E-commerce Sales Analysis Dashboard

## Project Overview
An interactive Power BI dashboard for analyzing e-commerce sales performance.

## Dashboard Preview
![Dashboard Screenshot](e-commerce%20sales%20analysis%20dashboard.png)

## Key Performance Indicators
- Total Sales
- Total Orders
- Total Customers
- Total Quantity

## Analysis
- Monthly Sales Trend
- Top 10 Products by Sales
- Sales by Country
- Interactive Year and Country filters

## Tools Used
- Microsoft Power BI
- DAX
- Data Visualization
- Data Analysis

## Project File
E-Commerce_Sales_Analysis.pbix

## Objective
To analyze e-commerce transaction data and present business insights through an interactive dashboard.
